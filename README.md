# 인선이엔티(060150) 매립단가 분기 시계열 추출

DART 정기보고서(사업/반기/분기보고서) 및 감사보고서 원문에서 **단가 관련 항목을 전량 발췌**하고,
**매립단가를 2016년 1분기부터 분기별로** 정리해 엑셀로 출력하는 파이프라인.

## 현재 상태 — 완료

| 단계 | 산출물 | 결과 |
|---|---|---|
| 1. 공시 선별 | 정기보고서 43건 | 2015 4Q~2026 2Q, 누락 없음 |
| 2. 원문 수집 | `data/raw/` | **43건 전부 수집 성공, 실패 0** |
| 3. 단가 발췌 | `out/인선이엔티_매립단가_분기.xlsx` | 표 24,673셀 + 산문 614문장 발췌 |

### 핵심 결과

매립단가(매립폐기물 최종처리용역)는 **2019년 반기보고서부터 공시**된다.
2015 4Q~2019 1Q 구간은 추출 실패가 아니라 **보고서 단가표의 매립 행이 `-` 로 비어 있다**
(해당 기간 매립사업 미영위/미공시). `매립단가_분기` 시트의 `상태` 열에 `미공시` 로 표기하고,
`비고` 열에 그 근거가 된 원문 행을 그대로 남긴다.

공시된 29개 분기의 누계 단가는 2020년 164,007원/톤을 정점으로 2025년 70,524원/톤까지
하락한 뒤 2026년 74,618원/톤으로 반등했다.

## 실행

```bash
pip install openpyxl lxml requests

# 1) 분기 ↔ 출처 보고서 매핑 프레임 생성
python3 tools/build_frame.py \
  --xlsx "DART 공시목록.xlsx" \
  --out  "out/인선이엔티_매립단가_분기_수집프레임.xlsx"

# 2) DART 원문 수집 (dart.fss.or.kr 접근 가능한 환경에서)
#    OpenDART API 키가 있으면 export DART_API_KEY=... 후 실행 (권장 경로)

python3 tools/dart_fetch.py \
  --xlsx "DART 공시목록.xlsx" --outdir data/raw --since 2016-01-01

# 3) 단가 발췌 + 엑셀 출력
python3 tools/dart_extract.py \
  --raw data/raw --xlsx "DART 공시목록.xlsx" \
  --out "out/인선이엔티_매립단가_분기.xlsx"
```

## 발췌 대상

정기보고서 `II. 사업의 내용`에서 단가가 실리는 위치:

- `2. 주요 제품 및 서비스 > 주요 제품 등의 가격변동추이` — 매립 / 소각 / 건설폐기물 중간처리 /
  순환골재 / 자동차재활용(폐차) / 수집·운반 단가 (원/톤)
- `3. 원재료 및 생산설비 > 주요 원재료 가격변동추이` — 경유 등 매입단가
- `4. 매출 및 수주상황` — 품목별 매출액·물량으로 단가 역산 검증
- `7. 기타 참고사항` 등 **서술형 본문** — 표에 없이 문장으로만 언급되는 단가·처리비·반입료·
  판가 인상/인하 내용 (`산문_단가언급` 시트로 별도 수집)

매립단가는 **매립폐기물 처리용역 매출액 ÷ 처리량**으로 산출된 공시 수치다.

## 집계기준 — 공시 원값 + 단일분기 역산 병기

정기보고서의 가격변동추이는 **당해연도 누계 평균 단가**(= 누계 매출액 ÷ 누계 처리량)로
공시된다. 즉 반기보고서 값은 1~6월 누계, 사업보고서 값은 연간 누계다.

`매립단가_분기` 시트는 두 가지를 나란히 싣는다.

1. **공시 단가(누계)** — 보고서에 실린 수치 그대로. `집계기준` 열에 누계 구간 표기.
2. **단일분기 단가(역산)** — 인접 분기 누계 차분으로 복원한 해당 분기만의 단가.

역산식은 누계 물량을 `매출액 ÷ 단가` 로 복원한 뒤 차분한다.

```
p_Q(n) = ( rev(n) - rev(n-1) ) / ( rev(n)/p(n) - rev(n-1)/p(n-1) )
```

매출액 단위(원·천원·백만원)는 분자·분모에서 상쇄되므로 단위 환산이 필요 없다.
1분기는 누계 = 단일분기이므로 공시값을 그대로 쓴다.

검증: 알려진 분기값으로 합성한 공시 누계 데이터를 넣어 4개 분기 전부
**오차 0.01% 이내**로 복원함을 확인했다. 잔여 오차는 공시 누계단가가 정수로
반올림된 데서 오며, 분기 물량 비중이 10% 미만이면 오차가 증폭될 수 있어
`역산 비고` 열에 경고를 표기한다. 부문별 누계 매출액을 못 구한 분기는
역산값을 비우고 사유를 남긴다.

## 출력 시트

| # | 시트 | 내용 |
|---|---|---|
| 1 | `요약` | 수집 범위, 매립단가 요약(최고·최저·최근), 연도별 표, 추이 차트 |
| 2 | `매립단가_분기` | 43개 분기 전량. 공시 누계 + 단일분기 역산 + 출처·접수번호·DART 링크. 미공시 분기는 회색 음영과 근거 원문 표기 |
| 3 | `단가_품목별_분기` | 품목 × 분기 피벗 (중간처리·순환골재·매립) |
| 4 | `단가항목_전체` | 전 품목 단가 롱 포맷 |
| 5 | `산문_단가언급` | 표가 아닌 **서술형 문장** 속 단가 언급 (문장 원문 + 추출 금액) |
| 6 | `출처_공시목록` | 발췌에 사용한 공시 목록 + DART 원문 링크 |
| 7 | `수집로그` | 보고서별 표 개수 / 단가 관련 표 / 산문 언급 수 |
| 8 | `원자료_발췌표` | 단가·매출 관련 표를 원본 셀 단위 그대로 발췌 (감사 추적용) |

### 서식

Arial · 헤더 `#523227` 흰 글씨 · 미공시 행 `#F7EFDA` 음영 · 단가 `#,##0` · 전 시트 고정틀·필터.

`요약` 시트의 수치는 수식이 아니라 발췌 데이터에서 계산한 값으로 기록한다.
이 워크북은 확정된 공시 원문에서 `tools/dart_extract.py` 가 통째로 재생성하는
산출물이라 셀을 손으로 고쳐 재계산할 대상이 아니며, 원문이 갱신되면 스크립트를
다시 돌려 전체를 생성한다.
