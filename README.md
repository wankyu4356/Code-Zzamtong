# DART 정기보고서 품목별 단가 분기 시계열

DART 정기보고서(사업/반기/분기보고서) 원문에서 **단가 관련 항목을 전량 발췌**하고,
품목별 단가를 **분기 시계열**로 정리해 엑셀로 출력하는 파이프라인.
회사·품목에 종속되지 않게 만들어져 공시목록 엑셀만 바꾸면 다른 회사에도 그대로 돌아간다.

## 산출물

| 회사 | 기간 | 품목 | 파일 |
|---|---|---|---|
| 인선이엔티 (060150) | 2015 4Q ~ 2026 2Q (43분기) | 건설폐기물 중간처리 · 순환골재 · 매립 | `out/인선이엔티_품목별단가_분기.xlsx` |
| 코엔텍 (029960) | 2016 4Q ~ 2025 4Q (37분기) | 소각 · 스팀 · 매립 | `out/코엔텍_품목별단가_분기.xlsx` |

인선이엔티는 **소각 단가를 공시하지 않는다** (전 기간 0건). 단가표 품목이
건설폐기물 중간처리용역 · 매립폐기물 최종처리용역 · 순환골재판매 뿐이다.

## 실행

```bash
pip install openpyxl lxml requests formulas

# 1) DART 원문 수집
python3 tools/dart_fetch.py --xlsx "<공시목록>.xlsx" --outdir data/raw --since 2017-01-01

# 2) 발췌 + 엑셀 생성
python3 tools/dart_extract.py --raw data/raw --xlsx "<공시목록>.xlsx" \
  --company "회사명 (종목코드)" --out "out/회사명_품목별단가_분기.xlsx"

# 3) 수식 검증 (발췌 레코드에서 독립 산출한 기대값과 대조)
python3 tools/gen_expected.py "<공시목록>.xlsx" data/raw /tmp/expected.tsv
python3 tools/verify_formulas.py "out/회사명_품목별단가_분기.xlsx" /tmp/expected.tsv

# 4) 수식 셀에 계산 결과 캐시값 주입 (뷰어에서 빈 칸으로 보이지 않게)
python3 tools/cache_values.py "out/회사명_품목별단가_분기.xlsx"
```

## 회사별 차이를 흡수하는 부분

공시 서식은 회사마다 다르다. 아래는 전부 원문에서 읽어 자동 처리한다.

| 항목 | 인선이엔티 | 코엔텍 |
|---|---|---|
| 단가 단위 | `원/톤` | `천원/톤` |
| 열머리 | `2026년 (제30기 반기)` | `제33기` (연도 없음) |
| 단위 표기 위치 | 표 앞 문단 | 표 앞의 **한 칸짜리 별도 table** |
| 매출표 | 매출액 1열 | 수량·금액 **2열 쌍**, 2단 머리글 |
| 매출액 단위 | 천원 | 보고서에 따라 **천원 ↔ 백만원** |
| 수량 공시 | 없음 | 있음 |

- **당기 열 판정**: 열머리에 연도가 없는 회사가 있어 문자열 매칭 대신
  '숫자가 처음 나오는 열과 최상단 머리글이 같은 열'로 위치 판정한다.
- **매출 항목 매칭**: 단가 품목명과 매출 품목명 표기가 달라
  (`매립폐기물 최종처리용역` ↔ `매립폐기물최종처리 용역 …`,
  `소각부분(내수) 소각처리` ↔ `소각부문 처리매출 소각처리`),
  분기당 1건만 잡히는 검색어를 자동 탐색한다.

## 집계기준 — 공시 원값 + 단일분기 역산

정기보고서의 가격변동추이는 **당해연도 누계 평균 단가**로 공시된다.
반기보고서 값은 1~6월 누계, 사업보고서 값은 연간 누계다.
품목별 시트는 공시 누계값과 단일분기 역산값을 나란히 싣는다.

```excel
=IF($A16<>$A15,"",IFERROR(($G16-$G15)/($G16/$E16-$G15/$E15),""))
```

누계 물량을 `매출액 ÷ 단가`로 복원해 인접 분기 차분을 취한다.
매출액 단위는 분자·분모에서 상쇄되므로 단위 환산이 필요 없다.
알려진 분기값으로 합성한 데이터에서 4개 분기 전부 **오차 0.01% 이내** 복원을 확인했다.

## 공시 자체의 오류를 잡는 검증 열

코엔텍은 수량을 함께 공시하므로 `매출액 ÷ 수량`으로 단가를 독립 계산해 대조한다
(매출액 단위가 보고서마다 바뀌므로 단위 문자열에서 배율을 뽑아 환산).
괴리가 5%를 넘으면 비고에 경고를 띄우고, 역산은 직전 분기에 의존하므로
직전 분기가 어긋난 경우도 함께 경고한다.

이 검증으로 실제 공시 오류 2건을 찾았다.

- **2024 3Q 소각**: 단가표는 152.5 천원/톤을 싣지만 같은 보고서 매출실적으로
  계산하면 19,192백만원 ÷ 152,553톤 = 125.8. 자릿수가 뒤바뀐 것으로 보인다.
- **2017 1Q**: 매출실적표의 품목 라벨이 한 칸씩 밀려 있다. 같은 보고서 생산실적표와
  숫자는 같은데 품목 배정이 다르며, 가격변동추이(매립 76.959 × 35,162톤 =
  2,706,030천원)와 맞아떨어지는 쪽은 생산실적표다.

## 출력 시트

| # | 시트 | 내용 |
|---|---|---|
| 1 | `요약` | 수집 범위, 품목별 최고·최저·최근, 연도별 표, 추이 차트 |
| 2~ | `<품목>단가_분기` | 품목별 분기 전량. 공시 누계 + 단일분기 역산 + 수량·검증 단가 + 출처·DART 링크 |
| | `단가_품목별_분기` | 품목 × 분기 피벗 |
| | `단가항목_전체` | 전 품목 단가 롱 포맷 |
| | `산문_단가언급` | 표가 아닌 **서술형 문장** 속 단가 언급 |
| | `출처_공시목록` | 발췌에 사용한 공시 + DART 원문 링크 |
| | `수집로그` | 보고서별 표 개수 / 단가 관련 표 / 산문 언급 수 |
| | `원자료_발췌표` | 단가·매출 관련 표를 원본 셀 단위 그대로 발췌 (감사 추적용) |

## 값과 수식

원문에서 발췌한 값만 상수로 두고(**파란 글씨** = 입력), 파생값은 전부 수식과
시트 간 참조로 계산한다(검정 = 수식).

```
원자료_발췌표 ─┬─> 단가항목_전체 ─┬─> 단가_품목별_분기
               │                  └─> <품목>단가_분기 ─> 요약
               └────────────────────> <품목>단가_분기 (누계 매출액·수량)
```

### 수식 검증

이 환경의 LibreOffice 는 xlsx 를 전혀 열지 못해(`source file could not be loaded`)
skills 의 `recalc.py` 를 쓸 수 없다. 대신 `formulas` 라이브러리로 모든 수식을 실제
계산해, 발췌 레코드에서 독립적으로 구한 기대값과 대조한다.
**인선이엔티 702셀 · 코엔텍 606셀 · 불일치 0건.**

openpyxl 은 수식 셀에 빈 `<v></v>` 만 남겨 재계산하지 않는 뷰어에서 빈 칸으로 보이므로,
`tools/cache_values.py` 로 계산 결과를 캐시값으로 주입한다. 수식은 그대로 남는다.
