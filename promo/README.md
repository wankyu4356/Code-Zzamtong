# 김철신정형외과 브랜드 필름

애플 티저 문법(검은 화면, 큰 글자, 박자마다 임팩트, 1박 1단어 드롭)으로 만드는 45초 안팎의 병원 브랜드 영상.

| 경로 | 내용 |
|---|---|
| `storyboard_v1.md` | 구성안 1차 (50초, 48샷). 의뢰인 확인 후 제작 착수. `tools/storyboard_page.py`로 검토용 웹 페이지를 만든다 |
| `engine/` | 렌더 파이프라인. 타임라인 JSON에서 실사 배경(ffmpeg)과 글자 레이어(Chromium)를 만들어 합성 |
| `music/` | 배경음악 합성 엔진과 스코어. `preview/music_v1.mp3`가 구성안 v1 기준 렌더 |
| `assets/` | 로고(원본·흰색), 네이버 리뷰 원문 70건과 선별본, 병원 사실 정보. 무료 영상과 병원 사진은 아직 없음 |
| `tools/` | 네이버 리뷰 수집기, Pexels 영상 수집기, 구성안 페이지 생성기 |

## 제작 순서

1. 구성안 확정 (브랜드 한 줄, 리뷰 사용 범위, 원장 노출 여부)
2. 소스 수집: 무료 영상(Pexels, Pixabay, Mixkit), 병원 실제 사진과 로고, 네이버 리뷰 원문
3. `music/score.json`에 임팩트 시점을 적고 배경음악 렌더
4. `engine/timeline.json`에 샷 리스트를 옮기고 `python3 engine/run.py` 실행
5. 프리뷰 확인 후 최종 렌더

## 이 세션에서 확인된 제약

- 세션 네트워크 정책이 naver.com, pexels.com, pixabay.com 등 외부 사이트를 막고 있어 영상 소스를 직접 내려받지 못했다. 리뷰와 소개글은 의뢰인이 복사해 주어 확보했다. 영상은 허용 도메인에 pexels.com을 추가하거나 파일로 넘겨주면 바로 조립 가능
- 병원 내부·외부 장면은 실제 사진만 쓴다. 무료 소스의 다른 병원 장면은 쓰지 않는다

## 제작 노트 (v1 조립, 2026-09-26)

- 실사 22컷은 Mixkit 무료 영상(상업 사용 가능, 출처 표기 불필요)에서 골랐다. 샷별 선택 근거와 검수 의견은 `assets/footage/picks/`에, 실제 쓰는 구간만 잘라낸 클립은 `assets/footage/final/`에 있다
- 구성안과 달라진 점
  - 샷 9 "수능 앞, 목.": 책상 앞 수험생 클립을 찾지 못해 구성안이 허용한 대로 검은 화면에 글자만
  - 샷 11 "계단 앞, 무릎.": 계단 난간 대신 지팡이를 짚은 노인의 손. 계단·무릎이 직접 보이진 않지만 인물과 자막이 모순되지 않아 채택
  - 샷 25 "앉고": 사무실 의자에 앉는 순간이 담긴 클립이 없어 도서관에서 쪼그려 앉는 순간으로 대체
  - 샷 13 "짧은 시간이라도,": 판독 모니터 사진 대신 접수 데스크 실제 사진
  - 샷 26 "목"은 세로 소스라 가운데를 잘라 썼고, 샷 27 "어깨"는 와이드샷이라 1.25배 펀치인
- 건물 외관 사진은 세로 사진의 간판 띠를 잘라 썼다. 4번 출구 쪽에서 가로로 찍은 사진이 오면 샷 44·45를 교체한다
- 리뷰 5건은 화면에 붙여 넣는 대신 실제로 입력하는 장면으로 처리했다. `engine/hangul.py`가 두벌식 키 순서와 입력기 중간 조합(지, 진, 짅, 진자)을 만들고, 키마다 클릭 효과음이 붙으며 마지막에 등록 버튼이 눌린다. 리뷰 슬롯은 글자 수에 비례해 24.0~26.37, 26.37~29.87, 29.87~32.0으로 다시 나눴다
- 리뷰 구간은 두 가지 버전으로 렌더한다. A안 `timeline_v1.json`(리뷰 작성 카드에 실제 타이핑), B안 `timeline_v1_chat.json`(메신저 말풍선. 입력 중 점 세 개, 말풍선 도착과 알림음, 앞 말풍선이 위로 밀림). `python3 build_timeline.py --reviews chat`이 B안을 만든다
- C안 `timeline_v1_receipt.json`: 리뷰가 영수증처럼 프린터에서 한 줄씩 인쇄되어 나오고 뜯겨 떨어진다(네이버 영수증 인증을 그대로 사물로 옮긴 것). `--reviews receipt`
- 2026-09-27 A안(타이핑)과 B안(메신저)을 새 접수 사진으로 다시 렌더했다: `render/kimcheolsin_brand_film_v1_typing_newphoto_*`, `render/kimcheolsin_brand_film_v1B_chat_newphoto_*`. 원본 렌더와 프레임을 비교해 접수 사진 화면(12~13초)만 달라지고 나머지 화면과 소리는 원본과 같음을 확인했다
- 엔진 호환: 네 번째 영상에서 강타 시작 흐림을 배율에 비례하게 바꾼 것이 예전 영상에도 걸려 있었다. 이제 글자에 `hit_blur`를 줄 때만 비례 흐림이 적용되고(네 번째 영상 빌더가 넣는다), 없으면 예전과 같은 1px이다

## 두 번째 영상 (2026-09-26): 토요일, 내 무릎의 하루

첫 번째 영상과 뿌리부터 다른 안. 구성안은 `film2/storyboard_film2.md`, 콘셉트 심사 기록은 `film2/concepts_judged.json`.

- 1인칭 하루. 글자 대신 영상이 앞에 서고, 속마음은 화면 아래 세리프 자막(Noto Serif CJK KR 44px)으로만 적는다. 검은 화면은 첫 0.5초뿐, 리뷰와 브랜드 문장은 크림색 종이 화면 위에 놓는다
- 소리는 비트 없이 공간별 룸톤, 발소리, 엘리베이터 버튼, 펜, 종이, 새소리, 펠트 피아노 몇 음과 패드, 벨 하나. `music/film2_audio.py`가 `music/score_film2.json`을 읽어 만들고 -17.5 LUFS로 맞춘다 (pedalboard Limiter는 메이크업 게인이 붙어 자체 피크 리미터로 대체)
- 실사 11컷은 Mixkit에서 골랐다. 선별 기록은 `assets/footage2/picks/`, 편집자 확정은 `assets/footage2/final_picks.json`, 쓰는 구간만 자른 클립은 `assets/footage2/final/` (`tools/trim_final.py`)
- `build_film2.py`가 타임라인을 만든다. 샷별 펀치인·색온도·속도는 `OVERRIDES`, 자막 색은 배경 밝기를 재서 크림색/잉크색을 고른다
- 구성안과 달라진 점
  - 건물 외관 사진은 다른 병원 간판이 화면을 차지해 밝은 3초 컷으로 쓰지 않았다
  - 유리문 손잡이 POV가 Mixkit에 없어 엘리베이터 버튼을 누르는 손(5~6층으로 올라간다)으로 바꿨다
  - 계단 두 컷은 운동화 차림의 발 POV가 없어(하이힐뿐) 위에서 내려다본 빈 계단 POV를 느리게 늘려 썼다. 같은 계단이 아침과 오후에 두 번 나오는 구조는 그대로
  - 지하철 출구는 에스컬레이터 발판 위 내 발 POV로, 창가 햇빛은 블라인드 사이로 드는 빛과 손가락으로
  - 펜 클립은 해부 스케치라 펜 끝과 빗금만 보이게 크게 잘랐다
- 렌더: `python3 engine/run.py engine/timeline_film2.json --build engine/build_film2c` (경로는 절대 경로 권장. concat 목록이 상대 경로면 ffmpeg가 목록 파일 위치 기준으로 읽어 실패한다)

## 세 번째 영상 (2026-09-26): 듣는 정형외과

두 번째 안(1인칭 하루)은 의뢰인이 "트렌디하지 않고 AI 같다"고 폐기했다. 세 번째 안은 애플 광고 문법의 타이포그래피 필름이다. 구성안은 `film3/storyboard_film3.md`.

- 카피는 워크플로로 만들었다. 카피라이터 5명(애플 톤, 질문형, 숫자형, 재치형, "듣는다" 변주)이 안을 쓰고, 안마다 4개 렌즈(애플다움, 카피 완성도와 AI 냄새, 40~60대 가독성, 의료광고 안전)로 심사한 뒤 종합하고, 심사위원 3명이 AI 냄새와 어색한 표현을 반박 검수해 한 번 더 고쳤다. 기록은 `film3/copy_workflow_result.json`
- 화면은 흰(#f5f5f7)과 검은 화면에 Pretendard 굵은 글자, 강조색은 로고 남색 하나. 실사는 원장 사진과 접수 데스크 사진뿐이고 무료 스톡 영상은 쓰지 않는다
- `build_film3.py`가 `film3/script.json`을 읽어 타임라인을 만든다. 단어별 등장(words), 줄 단위 등장(stack), 큰 따옴표 인용(quote), 엔딩(브랜드 줄이 위로 물러나고 로고·명칭·정보)을 처리한다
- 음악은 `music/compose_film3.py`. 120 BPM 킥·스냅·서브·플럭 훅, 컷마다 스냅, "다 듣습니다."와 "듣는 정형외과." 앞에서 완전 무음, 엔딩 코드. -14 LUFS
- 렌더 뒤 아트 디렉터 심사 워크플로(애플다움, 가독성, 사진 화면, 움직임)로 수정 목록을 받아 반영했다

## 네 번째 영상 (2026-09-27): 뼈부터 정맥까지

의뢰인 요청: 당연한 소리 지양, 완전히 새로운 애플 콘셉트, 질환·치료 범위에 방점, 원장 이력, 유려하고 참신한 글자 효과, 표현 하나하나 검토. 구성안은 `film4/storyboard_film4.md`.

- 원장 이력은 의뢰인이 보낸 프로필 카드(`assets/hospital/doctor_profile_card.jpg`)에서 `facts.md`로 옮겼다. 대표원장은 유병찬
- 카피 워크플로 기록 `film4/copy_workflow_result.json`, 시각 심사 기록 `film4/visual_qc_result.json`
- 엔진에 글자 효과를 더했다: track(흐린 글자가 조여지며 선명, track_from), wipe(빛 스윕), slot(빈자리 단어가 굴러 바뀌고 폭이 따라 움직임, 마지막 단어는 살짝 넘쳤다 섬, 강조색이 본문색으로 돌아옴), ticker, grid(격자 점등), count, 따옴표 내밀기(hang_quotes), 위치·크기 이동(y_to, scale_to, move_ease, ls_to), 옅어지다 멈춤(out_to)
- `build_film4.py`가 `film4/script.json`을 읽는다. 음악은 `tools/score_from_script.py`가 구성안의 소리 표기에서 스코어를 만들고 `music/compose_film3.py`로 렌더한다 (D 단조)
- 글자 모션 사양은 `film4/motion.json`, 어휘 설명은 `film4/motion_api.md`, 프레임 검수 기록은 `film4/motion_qc_result.json`. 빌더가 사양을 타임라인에 입힌다(`--no-motion`으로 끌 수 있음). 엔진 추가: 글자·단어·줄 단위 등장(reveal)과 퇴장(exit, zoom 포함), 빛 스윕(sheen), 밑줄, 초점 등장(focus), 원형 전환(shape_wipe, 가장자리가 번질수록 넓어짐), 선 긋기(line_draw), 배경 밀어 넣기(push_out)
- 접수 데스크 사진은 의뢰인이 다시 보낸 원본(`assets/hospital/reception.png`)으로 바꿨다. 이전 사진은 `reception_old.png`로 남겼다. `reception_16x9.jpg`는 이 사진을 1920×1080으로 채워 만든 것이라 첫~세 번째 영상도 다시 렌더하면 새 사진이 들어간다
- 합성 버그 수정: 화면을 완전히 덮는 프레임을 Chromium이 알파 없는 PNG로 저장하면 ffmpeg이 필터를 다시 초기화하며 한 프레임을 버리고 앞 프레임을 반복했다. `engine/compose.py`가 합성 전에 모든 오버레이 프레임을 RGBA로 맞춘다
