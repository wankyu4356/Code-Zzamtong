# 리뷰 후보 (검색 결과 요약에서 확인된 문장)

아래 문장은 모두닥·캐시닥 검색 요약에 인용된 리뷰다. 원문 페이지를 직접 열지 못해
플랫폼과 작성일을 확정하지 못했다. 영상에 쓰기 전에 네이버 플레이스나 모두닥에서 원문을 확인하고 캡처를 남길 것.

1. "과잉 진료 없으시고 부담스러울정도로 원장님 친절하십니다"
2. "의사선생님이 엄청 친절하시고 꼼꼼하고 정성스럽게 봐주시는게 느껴졌습니다"
3. "과잉진료 없으시고, 아픈곳 잘 찾아내셔서 좋았어요"

## 영상에 쓸 리뷰를 고르는 기준

- 친절, 설명, 꼼꼼함, 과잉진료 없음, 대기시간, 접근성처럼 서비스 품질을 말하는 문장
- "다 나았다", "통증이 사라졌다" 같은 치료 효과를 단정하는 문장은 제외 (의료광고 규제)
- 짧을수록 좋다. 한 화면에 두 줄 이내
- 네이버 플레이스 방문자 리뷰는 영수증 인증이라 신뢰도 표시에 유리
