# 세 번째 영상 구성안: 듣는 정형외과

애플 광고 문법의 타이포그래피 필름. 흰 화면과 검은 화면에 큰 글자, 실제 사진 두 장(원장, 접수 데스크), 리뷰는 큰 따옴표 인용. 49.5초, 18화면, 120 BPM. 컷은 박자에 맞고 핵심 문장 앞에는 무음.

핵심 아이디어 하나: 이 병원은 환자의 말을 끝까지 듣고, 필요한 치료만 한다. 병원은 순서만 말한다(말씀하세요 → 듣습니다 → 진찰 → 왜 아픈지 → 치료는 그다음 → 필요한 치료부터). 결과와 "만"은 환자 리뷰가 말한다.

리뷰 셋은 네이버 방문자 리뷰 원문(영수증 인증)에서 문장 단위로 발췌했다. 캡션은 "네이버 방문자 리뷰 · 영수증 인증 · 발췌".

## 카피 판단 (심사에서 정리한 것)

- 시작과 끝을 "허리든, 무릎이든." / "목이든, 어깨든."으로 짝지어 주요 청자의 네 통증을 다 부른다. 영상 전체에서 쉼표는 이 두 화면뿐이다
- "10분이든, 30분이든." 같은 시간 표기는 진료 시간 보장으로 읽힐 수 있어 뺐다. 대신 "서두르지 않고 / 한 번에 한 분."
- 치료 효과를 병원이 단정하는 문장은 없다. "필요한 치료만"이라는 말도 환자 리뷰에서만 나온다
- 일요일 진료는 확인 전이라 어디에도 쓰지 않았다. 토요일은 시작·종료 시각까지 사실대로
- 브랜드 한 줄 "듣는 정형외과."는 형용사와 약속이 없어 심의에 걸릴 표현이 없고, 검색어와 겹친다

## 확인이 필요한 것

1. 브랜드 한 줄 "듣는 정형외과."
2. "주차 무료" 표기(차량 엘리베이터 조건 확인) 와 "걸어서 1분"(홈페이지 도보 1분, 네이버 102m)
3. 리뷰 작성자 3인의 사용 동의와 원장 초상 사용 동의
4. 유튜브·인스타그램 집행 전 의료광고 사전심의. 심의가 인용을 문제 삼으면 8·11·12번을 병원 문장("그림으로도 모형으로도." / "다시 물으셔도 됩니다." / "이해되실 때까지.")으로 바꾸는 B안이 준비돼 있다
